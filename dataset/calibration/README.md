# Production calibration data

This directory is generated by `nailong calibrate-visual` and is safe to use without
video at production time.

- `*_target_centroid.npy`: visually confirmed Nailoong voiceprint centroid.
- `*_other_centroid.npy`: visually confirmed Xiaoqi/other-speaker centroid.
- `calibration.json`: primary-model normalization, operating thresholds, leave-one-video-out
  validation metrics, model identifiers, and SHA-256 provenance.

The source of truth is `dataset/manifests/visual_labels.csv`. Video was used only for
offline calibration. The `non_speech` sample is evaluated as a reject case but is not
mixed into the other-speaker centroid.

The primary backend is selected by leave-one-video-out AUC. ReDimNet remains an audit
signal; the two-model average is diagnostic only because it performed worse than the
best individual backend on this calibration set.
